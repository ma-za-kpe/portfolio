03 How I work

AI does the typing. I own the outcome.

I built my engineering foundation before coding agents went mainstream. Now I use Claude Code and Codex to move faster, while I keep ownership of architecture, review, security and every release.

  1. 01

    Tests first, incidents pinned

    Every gate rule starts as a test. Every production incident becomes a regression test.

  2. 02

    Honest fallbacks

    When quality isn't there, the system says so instead of shipping filler.

  3. 03

    Provenance everywhere

    Source URL, quotes, content hash and signal strength on every row.

  4. 04

    Cost is a feature

    Budget reservations, billing ticks and caching are designed in from day one.

  5. 05

    Offline is the default

    Built for field agents on 2G: outboxes, retries and process-death recovery.

  6. 06

    Docs as code

    Architecture, runbooks and decisions are versioned next to the code they describe.
